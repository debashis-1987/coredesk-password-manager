Security, in plain words

Designed so that losing the vault file costs an attacker nothing — because it's useless without your secrets.

How the vault is protected

  • AES-256-GCM — the whole vault is one authenticated encrypted blob
  • PBKDF2-SHA256, 1,000,000 iterations — slows offline brute-force a million-fold
  • No passphrase stored anywhere — not even a hash exists to attack
  • Fresh nonce every save — tampering fails the integrity check

Ways to unlock

  • Master passphrase — the root credential
  • FIDO2 hardware key — e.g. a YubiKey: touch and you're in
  • Key file — optional second factor: stolen file + passphrase still isn't enough
  • Quick PIN — fast re-unlocks within a session (RAM only)

Everyday hardening

  • Auto-lock — after 5 idle minutes, 2FA codes vanish with it
  • Clipboard auto-clear — 30 seconds after any copy
  • System tray — stays one click away, locked while idle
  • Printable recovery kit — documents every unlock method
